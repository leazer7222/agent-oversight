## Lessons Learned this session

- **Supabase untyped select() returns GenericStringError in TypeScript**: When DB types aren't generated (`supabase gen types`), string-based `.select()` calls return `GenericStringError` instead of the actual row type. Cast `data as any[]` to avoid TS errors. A better long-term fix is to run `mcp__supabase__generate_typescript_types` and save to `src/lib/supabase/types.ts`.
