## New Lessons Learned
- Git worktrees in `.claude/worktrees/` get tracked as gitlinks if accidentally staged — always add to `.gitignore`
- Netlify requires `@netlify/plugin-nextjs` for server components and API routes
- Netlify build fails on gitlink entries with no `.gitmodules` URL — fix: `git rm --cached <path>`
- shadcn/ui deps (`@base-ui/react`, `cva`, `clsx`, `tailwind-merge`) must be installed in the main project, not just worktrees
