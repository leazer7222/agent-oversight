## Key decisions
- New ingest endpoint at `/api/telemetry/ingest` (not `/api/ingest`) to avoid conflict with existing agent oversight endpoint
- `raw_events` has both `created_at` (RFC-009 linter requirement) and `received_at` (RFC-003 semantic name); both default to `now()`
- Task type seeds use a DO block with a local variable for taxonomy_id — avoids hardcoded seed UUIDs
- Pricing seed covers: claude-opus-4-7, claude-sonnet-4-6, claude-haiku-4-5-20251001, gpt-4o, gpt-4o-mini, o1, o3-mini, gemini-2.0-flash, gemini-2.0-flash-exp, gemini-1.5-pro
- Auth for telemetry ingest: same `x-agent-secret` / `INGEST_SECRET` pattern as existing endpoint
- Deduplication: insert + catch Postgres error code 23505 (unique_violation), return 200 with duplicate:true
