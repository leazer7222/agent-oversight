## Architecture Decisions Locked

- **Workspace = context parameter, not an agent layer.** No Workspace Orchestrator. `workspace_id` is passed to the Team Orchestrator which loads the right docs. Workspace isolation is structural (scoped doc paths), not an agent tier.
- **Orchestrators are deterministic state machines.** No LLM calls in the Team Orchestrator. LLM judgment lives exclusively in specialist agents.
- **Specialist agents are stateless pure functions.** Receive pre-loaded context from the orchestrator. Call no external tools. Produce typed output conforming to a schema contract.
- **Schema contract before system prompt.** Order enforced: schema → prompt → code.
- **Skills taxonomy replaces the vague "skill" term:** reasoning profile, context inputs, schema contract, quality criteria, telemetry events.
- **PCA v1 has zero external MCP access.** Canonical docs + user input only. Jira, Slack, GitHub, Figma all deferred.
- **Control plane / knowledge plane separation confirmed.** Agent Oversight records fingerprints (doc hashes, bundle versions, model IDs, error categories). Workspaces own the content. Each workspace instantiates the knowledge plane pattern independently.
- **Global Orchestrator deferred** until 3+ teams exist and routing patterns are understood.

## New Lessons Learned This Session

- Python modules can't be imported from directories with hyphens — use `importlib.util.spec_from_file_location()` to load agents from hyphenated paths like `product-clarification-agent/`
- `OVERSIGHT_SECRET` in `.env.local` is the local Next.js dev server secret — agents calling production Vercel need `AGENT_OVERSIGHT_SECRET` with the production value
- Windows bash `set VAR=val` does not export to child processes — use `VAR=val python ...` prefix syntax
- `find_dotenv(".env.local", usecwd=True)` finds `.env.local` in the main repo root even when script runs from a worktree
- Register orchestrator in Supabase BEFORE worker agents that reference it via `parent_agent_id` — FK constraint fires on insert order
- The `trigger_type` check constraint on `agents` table does not accept `"orchestrator"` as a value — use `"manual"` for orchestrators
