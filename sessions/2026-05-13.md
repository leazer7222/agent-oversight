## New Lessons Learned
- Git worktrees in `.claude/worktrees/` don't have `node_modules` by default — create junction: `cmd /c mklink /J node_modules ..\..\..\node_modules`
- `typeof rows[0]` fails TypeScript when `rows` can be null — use explicit inline type or interface
- When tsc output is empty and exit code is 0, it means no errors (clean)
